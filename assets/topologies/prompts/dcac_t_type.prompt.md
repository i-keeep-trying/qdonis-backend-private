## Topology-Specific Rules: T-Type Inverter
- **Output voltage convention & automatic control scaling (OVERRIDES the items below)**: The AC output voltage requested by the user is the **line-to-line RMS** value (`V_ph,rms = V_LL / sqrt(3)`). The application computes and writes `VIN`, the load resistors (R15..R17) and inductors (L1..L3), the current references (`V_IREF_*` amplitude/frequency/phase), the feed-forward sources (`V_VFF_*` amplitude/frequency/phase) and the DC-link midpoint initial condition from the user's Vdc, V_LL, power and output frequency. Do NOT emit those, and do NOT edit any behavioural (B_*/E_*) source. Focus on semiconductor selection and ratings, the DC-link capacitors and the snubbers.
- **RMS Output Voltage**: Note that the AC output voltage requested by the user is the **RMS** value, NOT the peak value. You must calculate the peak value (`V_peak = V_rms * sqrt(2)`) when sizing components, calculating the modulation index, or setting the reference sine wave amplitude.
- **Input Voltage Scaling**: This topology uses a single DC input voltage source: `VIN`. You MUST explicitly include the `VIN` component in your JSON output and update its `voltage` parameter to EXACTLY match the user's requested DC input voltage (e.g., `"VIN": {"voltage": 400}`). Do NOT touch the `V1` or `V2` components, as they are carrier signals, not power sources.
- **Modulation**: CCM/DCM calculations do not apply. Ensure the modulation index and carrier/switching frequency are consistent with the target output voltage relative to the DC-link/input voltage. `modulation_index ≈ Vout_peak / (Vin / 2)`.
- **Anchor the Midpoint**: You MUST keep the balancing resistors `Rb1` and `Rb2` at a high resistance value (e.g., `100k`) to prevent artificial massive power dissipation on the DC link. Do NOT set them to low values like 100 Ohms.
- **Target Currents (Peak vs RMS)**: SPICE `SIN()` sources require the **Peak** amplitude, not RMS. You MUST explicitly calculate $I_{peak} = I_{rms} \times \sqrt{2}$. You MUST update the `amplitude` parameter for `V_IREF_A`, `V_IREF_B`, and `V_IREF_C` to this exact $I_{peak}$ value.
- **Feedforward Phase and Amplitude**: The AI MUST dynamically calculate the correct feedforward amplitude and phase angle for the given R-L load, or the simulation will fail violently due to phase fighting:
  1. Calculate load inductive reactance: $X_L = 2\pi \cdot f_{out} \cdot L$.
  2. Calculate total impedance magnitude: $|Z| = \sqrt{R_{LOAD}^2 + X_L^2}$.
  3. Calculate phase angle in degrees: $\phi = \arctan(X_L / R_{LOAD}) \cdot (180/\pi)$.
  4. Calculate Required Peak AC Voltage: $V_{ac,peak} = I_{peak} \cdot |Z|$.
  5. Calculate Feedforward Control Amplitude: $V_{FF} = V_{ac,peak} \cdot \frac{10}{V_{in} / 2}$ (Since the carrier is 10V, modulation gain is $(V_{in}/2)/10$).
  6. Update `V_VFF_A`, `V_VFF_B`, and `V_VFF_C` by setting their `amplitude` parameter to the exact calculated $V_{FF}$ and their `phase` parameter to the correct phase offsets ($\phi$, $-120+\phi$, $-240+\phi$).
- **MOSFET Selection**: You MUST replace the default MOSFET in the `models` array with a suitably rated physical MOSFET part number from the `MOSFET_DB_JSON` array based on the requested input voltage. For 400V, 600V, or 800V buses, you MUST choose a high-voltage device (e.g., 600V IGBT, 900V SiC, or 1200V SiC) to prevent avalanche breakdown.
- **Load Calculation**: To ensure the inverter outputs real active power (W) rather than reactive apparent power (VA), you MUST calculate the load resistors (`R15`, `R16`, `R17`) based on the requested output power and voltage: $R = \frac{(V_{out}/\sqrt{3})^2}{Power/3}$. You MUST also set the filter inductors (`L1`, `L2`, `L3`) to a small value (e.g. `0.001` for 1mH) so that the voltage drops primarily across the resistor.
- **Initial Conditions Scaling**: You MUST dynamically calculate and update the initial conditions in the `analysis` section (specifically `analysis.spice_settings.ic` and `analysis.transient.spice_settings.ic`) to exactly `"v(N008)=Vin / 2"` (e.g., for an 800V input, use `"v(N008)=400"`). Do NOT blindly copy the default 400V if Vin is 600V. Additionally, you MUST set `"use_ic": false` in `analysis.transient.spice_settings` to prevent the solver from skipping steady-state DC operating point calculations and causing massive inrush transients.
- **Modulation Logic Syntax**: Do NOT use line breaks `\n` or stray hyphens when defining the mathematical `expression` for behavioral sources (e.g., `B_CLO`). Keep expressions like `V(Tri)/2 - 5` strictly on a single line as a single continuous string to avoid SPICE syntax errors.
- **Carrier Period Consistency**: If you modify the carrier period (`per`) on the `V1` pulse source to change the switching frequency, you MUST proportionally scale the rise (`tr`) and fall (`tf`) times so that `tr + tf + pw = per`. Do NOT leave a dead zone in the switching cycle.
- **Control Logic and Gains**: You MUST mathematically adjust the proportional gains (e.g. `*15`) and saturation limits (e.g., `min(max(..., -9.5), 9.5)`) if you scale the input voltage, to map this control signal properly.
